# Privacy Policy

Dungeon Code is a workflow app for JetBrains YouTrack. It does not collect, transmit, or store any personal user data outside of the YouTrack instance where it is installed.

All data stays within your YouTrack server. The app does not use any external APIs, tracking services, or analytics.

If you have any concerns or questions, please contact the developer at https://github.com/Valyutik/dungeon-code/issues.
